### Core Features (Office Edition)

* **Custom Fillable Form Creation:** Create electronic forms from any document or scanned paper layout that clients or staff can fill out using the free **Filler Pilot** utility or standard **Adobe Reader**.
* **Virtual Printer Integration:** Installs a virtual "Form Pilot" printer driver that captures documents from any Windows application (Word, Excel, PDF viewers, browsers) and converts them into editable form templates.
* **Scanned Paper & TWAIN Support:** Imports scanned paper forms directly from TWAIN scanners or image files (JPG, BMP, TIF) with built-in alignment and image adjustment tools.
* **Database & Batch Form Filling:** Stores recurring entries in a built-in database to auto-populate repetitive fields across multi-page forms and export completed records as PDF files.

* **Office (€245.00):** Full Pro features plus fillable form creation for external distribution and data import.
